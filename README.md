## What is SimBricks?

SimBricks is a platform for creating and simulating virtual prototypes of modern
heterogeneous computer systems, enabling meaningful end-to-end evaluation in
simulation. It modularly combines and connects battle-tested simulators for the
different components of computer systems like machines (e.g. QEMU, gem5), hardware (e.g. Verilator,
FEMU), and networks (e.g. ns-3). SimBricks allows running unmodified full-system stacks,
including applications, operating systems, and hardware RTL.
